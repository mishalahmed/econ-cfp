# Econ calls for papers

Live dashboard: https://mishalahmed.github.io/econ-cfp/

Calls for papers for economics conferences (general interest, IO, labor, education, urban) in the US, Canada,
Europe and East Asia. The data in `data/` is refreshed weekly from the organizers' websites; `build_site.py`
combines it into `data.json` for the page. Always confirm details on the official call.
